# 安全与兼容边界

## 无需安装 APK

手机端使用包含 classes.dex 的 JAR，不包含 AndroidManifest.xml、Activity、Service、IME 或无障碍组件。由已授权的 ADB 推送到 `/data/local/tmp/android-background-test/`（目录 0700、文件 0600，启动前核对哈希），通过系统 app_process 以 shell 身份运行一个协调进程，进程名就是 android-background-test，没有会话 30 秒后自动退出。

该选择减少安装和组件暴露，不是伪装或规避检测。JAR 仍是设备端代码；ADB 授权、ROM 权限、系统防护和应用对自动化的检测仍有效。拒绝执行或黑屏时报告，不关闭安全设置或绕过受保护内容。

协调进程只接受 shell 身份（uid 2000）的连接，每个会话另有令牌；令牌只存放在调用方工作目录的 session.json（0600），不输出到命令行。电脑与手机之间通过 adb server 直连，不建立 adb forward。DEX 编译下限 API 31 不等于已验证的最低 Android 版本。

## 来源与完整性

产物、脚本和哈希都在本 Skill 内。清单能发现损坏，不能防止文件和清单同时被篡改。应从可信来源安装，后续固定发布版本并通过可信渠道提供校验值。

不安装来源不明的 helper APK，不复用碰巧存在的服务。以后若需安装式组件，须另说明必要性、权限、签名和卸载流程并取得同意，不作为静默回退。

## 隔离限度

独立屏不隔离 CPU/GPU、温度、内存、数据、通知、声音、同包进程、安装升级。目标包被其他任务使用时默认拒绝。

后台屏只在手机亮屏且已解锁时渲染（nubia NX888J、OPPO PLG110 实测），锁屏即暂停；不自动唤醒或解锁补救。截图、输入、生命周期和异常退出必须逐设备验证。

关闭会话时只移除仍在后台屏上的任务和本会话残留的最近任务记录；已被用户拿到主屏的任务归用户，不会被移除。协调进程被强制杀死时，下次启动会清理上次留下的最近任务记录。

已验证设备：nubia NX888J（Android 17，测试版系统）、OPPO PLG110（ColorOS，Android 17，PLG110_17.0.0.105）。用户从桌面打开被占用应用时，这两台都把任务交给用户，检测和询问正常。早期另一个项目在 ColorOS 上见过任务留在后台屏、用户看不到的情况，本 Skill 在 PLG110 上没有复现；遇到这种情况的检测尚未实现，其他 ColorOS 版本未验证。预览和人工接管未实现；未来使用现成浏览器，能力不足明确报告，不偷偷安装重型播放器。
